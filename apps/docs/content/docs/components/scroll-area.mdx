## API Reference

### ScrollArea

Extends Base UI's `ScrollArea.Root` primitive and accepts all its props. Children are rendered inside the viewport.

### ScrollBar

Extends Base UI's `ScrollArea.Scrollbar` primitive and accepts all its props.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |
